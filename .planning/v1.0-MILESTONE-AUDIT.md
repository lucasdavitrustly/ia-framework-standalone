## Integration Gaps (Remediated 2026-04-03)

All 3 integration gaps identified in the initial audit have been resolved:

### Gap 1: Project Detector Orphaned — RESOLVED

**Fix applied:** `ia-framework init` CLI command added (`packages/cli/src/commands/init.command.ts`) which calls `detectProject()` + `confirmProfile()` + `persistProfile()`. `init-config.sh` now calls this command instead of writing hardcoded defaults.

**Verification:** `init.command.test.ts` — 9 tests, all passing.

### Gap 2: DependencyGraph Never Populated — RESOLVED

**Fix applied:**

- `packages/cli/src/commands/index.command.ts` — creates and passes `DependencyGraph` instance to `IndexingPipeline`
- `packages/dashboard-api/src/server.ts` — passes `DependencyGraph` to `triggerIndexing`
- `packages/mcp-server/src/bin.ts` — creates `DependencyGraph` for `SearchEngine` reads

**Verification:** `index.command.ts` confirmed to import and wire `DependencyGraph`.

### Gap 3: CLI Search Uses Basic Search — RESOLVED

**Fix applied:** `packages/cli/src/commands/search.command.ts` now calls `searchEngine.searchWithExpansion()` with a `DependencyGraph` instance. The `retrieval.mode` config controls whether expansion is applied.

**Verification:** `search.command.ts` confirmed to use `searchWithExpansion`.
