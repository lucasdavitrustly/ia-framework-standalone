## Integration Gaps

### Gap 1: Project Detector Orphaned (Critical)

**Phase 2 → Phase 5 wiring broken**

`project-detector` package (detectProject, confirmProfile, persistProfile) is fully implemented and tested, but `install.sh → init-config.sh` writes hardcoded defaults instead of calling it.

**Affected requirements:** INST-05 (detection occurs but is never invoked), INST-06 (confirmation exists but unreachable), DASH-05 (shows hardcoded config)

**Fix:** Wire project-detector into install flow via `tsx` call in init-config.sh or add `ia-framework init` CLI command.

### Gap 2: DependencyGraph Never Populated (Critical)

**Phase 10 → Phase 3/5 wiring broken**

DependencyGraph class and IndexingPipeline's dependencyGraph option exist, but:
- `packages/cli/src/commands/index.command.ts` — no dependencyGraph passed
- `packages/dashboard-api/src/server.ts` (triggerIndexing) — no dependencyGraph passed
- `packages/mcp-server/src/bin.ts` — creates DependencyGraph for reading, but it's empty

**Affected requirements:** INDX-05, RETR-03

**Fix:** Pass DependencyGraph instance to IndexingPipeline in CLI index command and dashboard triggerIndexing (~3 lines each).

### Gap 3: CLI Search Uses Basic Search (Minor)

**Phase 10 → Phase 5 wiring incomplete**

CLI `search` command calls `SearchEngine.search()` not `searchWithExpansion()`. Only MCP server uses graph expansion.

**Affected requirements:** RETR-03 (partial — only MCP path expands), RETR-05 (config unused)

**Fix:** Update search.command.ts to use searchWithExpansion() and respect retrieval.mode config.
