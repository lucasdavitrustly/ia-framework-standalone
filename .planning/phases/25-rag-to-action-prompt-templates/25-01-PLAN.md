  <implementation>
    1. Create `packages/mcp-server/src/templates/` directory structure

    2. `intent-detector.ts`:
       - Export type `IntentType = 'impact-analysis' | 'dependency-trace'`
       - Export function `detectIntent(query: string): IntentType | null`
       - Normalize query to lowercase
       - Impact/change patterns (per D-01): "what files", "what changes", "need to update", "affects", "impact of", "if i change", "breaking change"
       - Dependency trace patterns (per D-01): "depends on", "dependency chain", "what uses", "callers of"
       - Return first matching intent or null
       - Per D-06: keyword heuristics only, no LLM calls

    3. `impact-analysis.ts`:
       - Export const `IMPACT_ANALYSIS_TEMPLATE` (per D-03):
         ```
         You are analyzing change impact. Using the code references below:
         1. List affected files in dependency order (most directly affected first)
         2. For each file, explain WHY it needs updating (interface change, data contract, logic dependency)
         3. Estimate effort: S (<1h), M (1-4h), L (>4h)
         4. Note any files that are safe to leave unchanged and why
         ```

    4. `dependency-trace.ts`:
       - Export const `DEPENDENCY_TRACE_TEMPLATE`:
         ```
         You are tracing dependencies. Using the code references below:
         1. Map the dependency chain from the target to all dependents
         2. Distinguish direct dependencies from transitive ones
         3. For each dependency, note the coupling type (import, interface implementation, data contract, runtime call)
         4. Highlight any circular dependencies or tightly coupled clusters
         ```

    5. `registry.ts`:
       - Import both templates
       - Export `const TEMPLATES: ReadonlyMap<IntentType, string>` mapping intent→template
       - Export function `getTemplate(intent: IntentType | null): string | undefined`

    6. `index.ts`:
       - Re-export `detectIntent`, `IntentType`, `getTemplate`, `TEMPLATES` from submodules

  </implementation>
