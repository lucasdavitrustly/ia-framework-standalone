# Plan 10-02: Graph-Expanded Retrieval + Retrieval Config

**Phase:** 10 — Advanced Retrieval & Workflow Integration
**Requirements:** RETR-03, RETR-04, RETR-05
**Estimated:** ~20 min
**TDD:** Yes — expansion logic test-first

## Goal

Add graph-expanded retrieval to `SearchEngine` (1-2 hop expansion via `DependencyGraph`), add a `retrieval` config section to `ProjectConfig`, wire expansion into the MCP `search_codebase` tool, and document auto-context as deferred to v2.

## Context

Research spike (completed before execution) confirmed:
- **RETR-03** (graph expansion): Ready to implement. DependencyGraph from 10-01 provides `getNeighborFiles()`.
- **RETR-04** (auto-context): Deferred to v2. OpenCode doesn't support MCP Resources or Prompts. No `prompt.before` plugin hook. Tool-based approach is the practical alternative and is more token-efficient.
- **RETR-05** (retrieval mode config): Implement with `mcp-only` as the only functional mode. `auto-context` and `combined` reserved for v2.

## Decisions / Notes

- SearchEngine keeps DependencyGraph as an optional interface dependency — no hard coupling
- Expanded results use score: 0 to clearly distinguish from semantic matches
- expansionHops: 0 = no expansion (backward compatible)
- Auto-context deferred to v2 — documented with rationale and prerequisites
- retrieval.mode defaults to mcp-only (current behavior unchanged)
