Purpose: Method-level chunks currently lack enclosing context, causing fragmented retrieval results on architecture/cross-module queries. Adding preamble makes each chunk independently comprehensible.
Output: Updated `java.ts` parser, updated tests proving preamble and fallback behavior.

    **In `packages/ast-parser/src/parsers/java.ts`:**

    1. **Add `buildPreamble` function** that constructs the preamble string from:
       - Package declaration: find `package_declaration` node in root, extract its text (e.g., `package com.example.service;`)
       - Import declarations: collect all `import_declaration` node texts
       - Enclosing class/interface signature: the first line of the class/interface declaration (up to and including `{`)
       Concatenate: `{package}\n{imports joined by newline}\n{class signature}\n`

    2. **Refactor `collectDeclarations`** to differentiate between:
       - **Top-level class/interface/enum declarations** — chunk the entire declaration as-is (no preamble)
       - **Method/constructor/field declarations inside a class body** — prepend the preamble to `content`, set `parentName` to the enclosing class/interface name

       Implementation approach: when recursing into `class_body`/`interface_body`/`enum_body`, pass down the enclosing declaration's name and the preamble string. Method chunks get:
       ```typescript
       content: preamble + '\n\n' + methodSourceCode,
       parentName: enclosingClassName,
       ```

    3. **Extract package declaration**: Add helper `extractPackage(rootNode)` that finds `package_declaration` and returns its text or empty string.

    4. **Build class signature line**: For a class_declaration node, extract text from start of node to the first `{` (inclusive of that line). E.g., `public class OrderService extends BaseService implements Serializable {`

    **In `packages/ast-parser/src/chunker.ts`:**

    5. **Add fallback (per D-05):** Wrap the `parseJava(content, filePath, relativePath)` call in a try/catch. On any error:
       - Log a warning: `console.warn(\`[ast-parser] Java parse failed for \${filePath}, falling back to module chunk: \${error.message}\`)`
       - Return a single module chunk containing the entire file content (same pattern as the unsupported-language fallback on lines 33-53)
       - Set `language: 'java'`, `chunkType: 'module'`

    **Key details:**
    - Preamble blank-line separator: use `\n\n` between preamble and method body so it's visually distinct
    - `startLine`/`endLine` on method chunks should still reflect the METHOD's actual position in the file (not the preamble), since preamble is synthesized context
    - Do NOT change the `parseJava` function signature — it still takes `(sourceCode, filePath, relativePath)`
    - Do NOT modify TypeScript parser or splitter
