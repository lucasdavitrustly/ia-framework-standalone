    ### Step 2: Create benchmark.command.ts

    Create `packages/cli/src/commands/benchmark.command.ts` with a `benchmarkCommand()` function that returns a Commander `Command` with three subcommands: `run`, `list`, `history`.

    #### `benchmark run` subcommand
    Options:
    - `--config <path>` (default: `.ia-framework/project.json` via env/cwd convention)
    - `--top-k <n>` (default: 10)
    - `--threshold <n>` (default: 0.5)
    - `--baseline` (flag — sets scoreThreshold to 2.0)
    - `--label <text>` (optional human-readable label)
    - `--corpus <path>` (default: `<frameworkDir>/benchmark-queries.json`)

    Logic:
    1. Load `ProjectConfig` via `loadConfig(configPath)`
    2. Build `embeddingProvider` + `QdrantVectorStore` + `SearchEngine` (same pattern as search.command.ts)
    3. Resolve `corpusPath = options.corpus || join(frameworkDir, 'benchmark-queries.json')`
    4. Try `loadCorpus(corpusPath)`:
       - On `CorpusNotFoundError`: call `scaffoldExampleCorpus(corpusPath)`, print message:
         ```
         ✓ Created example corpus: <corpusPath>
         Edit the file to match your codebase, then re-run: ia-framework benchmark run
         ```
         Then exit 0 (don't run benchmark with example corpus that won't match)
    5. Resolve `topK` and `scoreThreshold` (if `--baseline`, set scoreThreshold=2.0 and topK=10)
    6. Build `ConfigSnapshot` from config + options
    7. Build `BenchmarkConfig` from options
    8. Run `await new BenchmarkRunner(searchEngine, benchmarkConfig).run(queries, configSnapshot)`
    9. Open `BenchmarkStore(join(frameworkDir, 'benchmarks.sqlite'))`, call `saveRun(run)`, then `close()`
    10. Print results table (see output format below)

    Output format for `benchmark run`:
    ```
    Benchmark Run: <runId slice 0-8> — <label or timestamp>
    Config: ollama/nomic-embed-text | top-k=10 | threshold=0.5
    Baseline: no

    ┌─────────────────────────┬───────────┬────────┬──────────────────┐
    │ Query                   │ Hit@10    │ Rank   │ Latency          │
    ├─────────────────────────┼───────────┼────────┼──────────────────┤
    │ authentication middleware│ ✓         │ 1      │ 45ms             │
    │ configuration loader    │ ✗         │ —      │ 38ms             │
    └─────────────────────────┴───────────┴────────┴──────────────────┘

    Summary
      Hit@10:       0.50 (1/2 queries)
      MRR:          0.50
      Avg Latency:  41ms
      Run ID:       abc12345
    ```

    Use plain Unicode box-drawing characters (─ ┌ ┐ └ ┘ ├ ┤ ┬ ┴ ┼ │). Truncate query text to 25 chars. Use `console.log()` for output (not logger, which goes to stderr).

    #### `benchmark list` subcommand
    Options: `--config <path>`, `--limit <n>` (default: 10)

    Logic:
    1. Open `BenchmarkStore(benchmarksDbPath)`
    2. `listRuns(limit)` → print table:
    ```
    Recent Benchmark Runs

    ID         Timestamp            Label           Hit@K   MRR    Baseline
    ─────────────────────────────────────────────────────────────────────────
    abc12345   2026-04-01 10:30:00  my first run    0.75    0.58   no
    def67890   2026-04-01 09:00:00  baseline        0.00    0.00   yes
    ```
    3. If no runs: print "No benchmark runs yet. Run: ia-framework benchmark run"

    #### `benchmark history` subcommand
    Options: `--config <path>`, `--limit <n>` (default: 20)

    Logic:
    1. Open `BenchmarkStore(benchmarksDbPath)`
    2. `listRuns(limit)` → print trend as ASCII chart:
    ```
    Hit@K Trend (last N runs, oldest → newest)

    1.0 ┤                 ●
    0.8 ┤           ●
    0.6 ┤     ●
    0.4 ┤ ●
    0.2 ┤
    0.0 ┼─────────────────────────

    ● = run (baseline runs shown as ○)
    ```
    ASCII chart: 10-row height, normalize hitAtK to 0.0–1.0 range. Each run = one column. Mark baselines with ○ instead of ●.

    If fewer than 2 runs: print "Not enough runs for trend (need ≥2). Run: ia-framework benchmark run"
