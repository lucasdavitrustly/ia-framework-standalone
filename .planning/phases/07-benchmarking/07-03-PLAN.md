    ### `benchmark compare <runId1> <runId2>` subcommand

    Arguments: two positional run IDs (full or prefix — support prefix match via `listRuns()` scan if exact match fails)
    Options: `--config <path>`

    Logic:
    1. Open `BenchmarkStore(benchmarksDbPath)`
    2. `getRunById(runId1)` and `getRunById(runId2)` (support short prefix: if not found by exact ID, scan `listRuns()` for first run whose `runId.startsWith(prefix)`)
    3. If either run not found, print `✗ Run not found: <id>` and exit 1
    4. `close()` store
    5. Print comparison:

    ```
    Benchmark Comparison
    ════════════════════════════════════════════════════════════════════

    Run A: abc12345 — 2026-04-01 10:30:00 "with RAG"
    Run B: def67890 — 2026-04-01 09:00:00 "baseline"

    ┌─────────────────────┬─────────────────────┬─────────────────────┐
    │ Config              │ Run A               │ Run B               │
    ├─────────────────────┼─────────────────────┼─────────────────────┤
    │ Provider            │ ollama              │ ollama              │
    │ Model               │ nomic-embed-text    │ nomic-embed-text    │
    │ Collection          │ my-project          │ my-project          │
    │ Top-K               │ 10                  │ 10                  │
    │ Threshold           │ 0.50                │ 2.00 (baseline)     │
    ├─────────────────────┼─────────────────────┼─────────────────────┤
    │ RESULTS             │                     │                     │
    ├─────────────────────┼─────────────────────┼─────────────────────┤
    │ Hit@K               │ 0.75  ↑ +0.75       │ 0.00                │
    │ MRR                 │ 0.58  ↑ +0.58       │ 0.00                │
    │ Avg Latency         │ 45ms                │ 12ms                │
    │ Queries Run         │ 4                   │ 4                   │
    └─────────────────────┴─────────────────────┴─────────────────────┘

    Per-Query Breakdown
    ┌──────────────────────────┬────────────┬────────────┐
    │ Query                    │ Run A Hit  │ Run B Hit  │
    ├──────────────────────────┼────────────┼────────────┤
    │ authentication middleware│ ✓ (rank 1) │ ✗          │
    │ configuration loader     │ ✓ (rank 3) │ ✗          │
    │ shared types interfaces  │ ✗          │ ✗          │
    │ error handler            │ ✓ (rank 2) │ ✗          │
    └──────────────────────────┴────────────┴────────────┘

    Verdict: Run A outperforms Run B by +0.75 Hit@K (+0.58 MRR)
    ```

    Delta arrows: ↑ if Run A > Run B, ↓ if Run A < Run B, = if equal. Deltas shown relative to Run B (baseline convention: compare RAG run vs baseline).

    For per-query breakdown, join queries by `queryId`. If a query appears in one run but not the other, show `—` for the missing run's column. Truncate query text to 26 chars.

    The "Verdict" line: if hitAtK delta > 0, say "Run A outperforms Run B by +X Hit@K (+Y MRR)". If equal, "Runs are equivalent". If Run A < Run B, "Run B outperforms Run A".

    Update the `benchmarkCommand()` Commander setup to add:
