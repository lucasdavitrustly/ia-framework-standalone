  <action>
    RED: Write tests in `packages/retrieval/src/mmr.test.ts` covering all behaviors above.

    GREEN: Implement in `packages/retrieval/src/mmr.ts`:

    1. `cosineSimilarity(a: number[], b: number[]): number` — dot product / (norm_a * norm_b). Handle zero-norm edge case (return 0).

    2. `jaccardSimilarity(textA: string, textB: string): number` — tokenize both by splitting on `/[^a-z0-9]+/` (lowercase), compute |intersection| / |union|. Return 0 if both empty.

    3. `classifyQueryLambda(query: string): number` — check lowercase query for architecture/synthesis keywords: "how", "architecture", "pattern", "overview", "communicate", "interact", "flow", "design", "structure". If any match → return 0.5. Else return 0.8. Per D-02.

    4. `mmrRerank(options: MmrOptions): RetrievalResult[]` where:
       ```typescript
       export interface MmrOptions {
         candidates: RetrievalResult[];
         queryVector?: number[];  // If provided, use cosine for relevance
         lambda: number;          // 0-1, controls relevance vs diversity
         limit: number;
         similarityFn?: (a: RetrievalResult, b: RetrievalResult) => number;
       }
       ```

       Algorithm (greedy iterative selection per D-01):
       - If no candidates, return [].
       - relevance(candidate) = candidate.score (already computed by Qdrant/RRF).
       - similarity(candidate, selected) = if `similarityFn` provided, use it. Otherwise use `jaccardSimilarity(candidate.content, selected.content)`.
       - selected = []
       - While selected.length < limit AND remaining candidates exist:
         - For each remaining candidate, compute: `λ * relevance(candidate) - (1-λ) * max(similarity(candidate, s) for s in selected)`. For first iteration (selected empty), score = λ * relevance(candidate).
         - Normalize relevance to [0,1] by dividing by max relevance across all original candidates (so relevance and similarity are on same scale).
         - Pick candidate with highest MMR score, move to selected.
       - Return selected.

    5. Export all functions from the module. Do NOT add to `packages/retrieval/src/index.ts` yet (that's Plan 02).

    REFACTOR: Ensure function signatures are clean, add JSDoc comments.
