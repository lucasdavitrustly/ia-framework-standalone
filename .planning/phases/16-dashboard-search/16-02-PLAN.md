    **Hook state** (per UI-SPEC):
    ```typescript
    const [state, setState] = useState<SearchState>('idle');
    const [query, setQuery] = useState('');
    const [collection, setCollection] = useState<'both' | 'ast' | 'llm'>('both');
    const [limit, setLimit] = useState(10);
    const [threshold, setThreshold] = useState(0.3);
    const [results, setResults] = useState<SearchResult[]>([]);
    ```

    **Collection loading (on mount)**: `useEffect` that calls `DashboardClient.getSearchCollections()`. On success: if empty array, setState('blocked'). Otherwise store in `collections` state. On error: leave state as 'idle' (graceful — collections just won't be available). Dependencies: `[]` (mount only).

    **handleSearch function**:
    1. If query is empty, return
    2. `setState('loading')`, `setExpandedId(null)`
    3. Call `DashboardClient.search({ query, limit, scoreThreshold: threshold, collections: [collection] })`
    4. On success with results.length > 0: `setResults(res.results)`, `setMetrics(res.metrics)`, `setState('results')`
    5. On success with 0 results: `setState('no-results')`
    6. On error: `setState('error')`

    **handleCompare function** (state transitions only — A/B UI rendering in Plan 03):
    1. If query is empty, return
    2. `setState('comparing')`, `setExpandedId(null)`
    3. Fire two parallel calls: `Promise.all([DashboardClient.search({ query, limit, scoreThreshold: threshold, collections: ['ast'] }), DashboardClient.search({ query, limit, scoreThreshold: threshold, collections: ['llm'] })])`
    4. On success: `setAbResults({ ast: res[0].results, llm: res[1].results })`, `setAbMetrics({ ast: res[0].metrics, llm: res[1].metrics })`, `setState('compared')`
    5. On error: `setState('compare-error')`

    **handleRetry function**: Calls `handleSearch()` (re-uses last query/settings).

    **Render** (per UI-SPEC §1 — `p-8` wrapper):
    ```tsx
    <div className="p-8">

      {state === 'blocked' ? (

      ) : (
        <>
          <SearchBar
            query={query}
            onQueryChange={setQuery}
            collection={collection}
            onCollectionChange={setCollection}
            limit={limit}
            onLimitChange={setLimit}
            threshold={threshold}
            onThresholdChange={setThreshold}
            onSearch={handleSearch}
            onCompare={handleCompare}
            disabled={state === 'loading' || state === 'comparing'}

          {state === 'idle' && <SearchEmpty />}

          {state === 'error' && <SearchError onRetry={handleRetry} />}
          {state === 'compare-error' && <SearchError onRetry={handleRetry} message="Comparison failed" />}
          {state === 'no-results' && <SearchNoResults threshold={threshold} />}
          {state === 'results' && (
            <SearchResultList
    ```
