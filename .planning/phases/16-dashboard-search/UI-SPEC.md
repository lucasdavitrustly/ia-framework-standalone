## Spacing Scale

Declared values (multiples of 4, matching existing dashboard patterns):

| Token | Value                 | Usage                                                                |
| ----- | --------------------- | -------------------------------------------------------------------- |
| xs    | 4px (`p-1`)           | Inline padding, icon gaps, pill badge vertical padding               |
| sm    | 8px (`p-2`, `gap-2`)  | Compact element spacing, control gaps, result row horizontal padding |
| md    | 16px (`p-4`, `gap-4`) | Default element spacing, card inner padding, grid gaps               |
| lg    | 24px (`p-6`, `mb-6`)  | Section separation (heading to content)                              |
| xl    | 32px (`p-8`)          | Page wrapper padding — matches all existing pages                    |
| 2xl   | 48px                  | Not used in this phase                                               |
| 3xl   | 64px                  | Not used in this phase                                               |

Exceptions: none.

## Typography

| Role       | Size | Weight         | Line Height | Tailwind Class          | Usage                                                         |
| ---------- | ---- | -------------- | ----------- | ----------------------- | ------------------------------------------------------------- |
| Body       | 14px | 400 (normal)   | 1.5         | `text-sm`               | Result row text, code preview, descriptions                   |

Source: Matches existing dashboard — Overview uses `text-xl font-semibold` for headings, `text-sm` for body text, `text-xs font-semibold` for labels.

## Component Inventory

### 1. SearchPage

**File:** `apps/dashboard/src/pages/SearchPage.tsx`
**Route:** `/rag/search` (D-32)

```
<div className="p-8">
  <h2 className="text-xl font-semibold text-gray-100 mb-6">Search</h2>
  {noCollections ? <NoCollectionsBlock /> : <>
    <SearchBar />
    {state === 'idle' && <SearchEmpty />}
    {state === 'loading' && <SearchSkeleton />}
    {state === 'error' && <SearchError />}
    {state === 'no-results' && <SearchNoResults />}
    {state === 'results' && !comparing && <>
      <SearchResultList results={results} />
      <MetricsPanel metrics={metrics} />
    </>}
    {state === 'results' && comparing && <ABComparisonLayout />}
  </>}
</div>
```

**State machine:**

| State           | Condition                                                | Renders                                       |
| --------------- | -------------------------------------------------------- | --------------------------------------------- |
| `blocked`       | No collections returned from GET /api/search/collections | NoCollectionsBlock                            |
| `idle`          | Page load, before first search                           | SearchEmpty                                   |
| `loading`       | Search request in flight                                 | SearchSkeleton (controls disabled per D-30)   |
| `results`       | Search returned ≥1 result                                | SearchResultList + MetricsPanel               |
| `no-results`    | Search returned 0 results                                | SearchNoResults                               |
| `error`         | Search request failed (network/Qdrant error)             | SearchError                                   |
| `comparing`     | A/B comparison in flight                                 | SearchSkeleton × 2 columns                    |
| `compared`      | A/B comparison complete                                  | ABComparisonLayout                            |
| `compare-error` | Either A/B call failed                                   | SearchError (full comparison failed per D-29) |

**State type:**

```typescript
type SearchState =
  | 'blocked'
  | 'idle'
  | 'loading'
  | 'results'
  | 'no-results'
  | 'error'
  | 'comparing'
  | 'compared'
  | 'compare-error';
```

**Hook state:**

```typescript
const [state, setState] = useState<SearchState>('idle');
const [query, setQuery] = useState('');
const [collection, setCollection] = useState<'both' | 'ast' | 'llm'>('both');
const [limit, setLimit] = useState(10);
const [threshold, setThreshold] = useState(0.3);
const [results, setResults] = useState<SearchResult[]>([]);
const [metrics, setMetrics] = useState<SearchMetrics | null>(null);
const [expandedId, setExpandedId] = useState<string | null>(null);
// A/B state
const [abResults, setAbResults] = useState<{ ast: SearchResult[]; llm: SearchResult[] } | null>(
  null,
);
const [abMetrics, setAbMetrics] = useState<{ ast: SearchMetrics; llm: SearchMetrics } | null>(null);
```

## Interaction Contracts

### Search Flow (D-09)

1. User types query in text input
2. User optionally adjusts collection, limit, threshold
3. User clicks "Search" button OR presses Enter
4. State transitions: `idle` → `loading` (controls disabled)
5. On success with results: `loading` → `results`
6. On success with 0 results: `loading` → `no-results`
7. On failure: `loading` → `error` (query preserved in input)

### A/B Compare Flow (D-19, D-26)

1. User types query and clicks "Compare" button
2. State transitions: `idle` → `comparing` (controls disabled)
3. Frontend fires two parallel `POST /api/search` calls:
   - Call 1: `{ query, limit, threshold, collections: ['ast'] }`
   - Call 2: `{ query, limit, threshold, collections: ['llm'] }`
4. If both succeed: `comparing` → `compared`
5. If either fails: `comparing` → `compare-error` (D-29: fail entire comparison)

### Result Row Expand/Collapse (D-01)

1. Click collapsed row → expand (show code preview)
2. Click expanded row → collapse
3. Only one row expanded at a time (clicking another collapses the current)
4. Mirrors `QueryEventTable` expand pattern with `expandedId` state

### Metrics Panel Toggle (D-15)

1. Panel shown expanded by default after search completes
2. Click "Metrics ▾" header → collapse panel (hide StatCards + chart)
3. Click "Metrics ▸" header → expand panel
4. State persists within session (not across page navigations)

## API Client Extensions

### New Types (in `apps/dashboard/src/api/client.ts`)

```typescript
// Search result DTO (D-24)
export interface SearchResult {
  id: string;
  filePath: string;
  startLine: number;
  endLine: number;
  score: number;
  source: 'ast' | 'llm';
  chunkType: string; // 'function' | 'class' | 'interface' | 'module' | etc
  matchedVector: string; // 'text' | 'code'
  content: string; // code chunk content for preview
  description?: string; // prose description if available
}

// Per-query metrics (D-24)
export interface SearchMetrics {
  latencyMs: number;
  chunksScanned: number;
  resultsReturned: number;
  scoreRange: { min: number; max: number };
}

// Search response (D-24)
export interface SearchResponse {
  results: SearchResult[];
  metrics: SearchMetrics;
}

// Search request body (D-23)
export interface SearchRequest {
  query: string;
  limit: number;
  scoreThreshold: number;
  collections: string[]; // collection names or ['both']
}

// Collection info (D-25)
export interface CollectionInfo {
  name: string;
  type: 'ast' | 'llm';
  chunkCount: number;
}
```

### New Client Methods

```typescript
export const DashboardClient = {
  // ... existing methods ...

  // D-25: Get available collections
  getSearchCollections: () => get<CollectionInfo[]>('/api/search/collections'),

  // D-23: Execute search
  search: async (request: SearchRequest): Promise<SearchResponse> => {
    const res = await fetch(`${BASE}/api/search`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(request),
    });
    if (!res.ok) throw new Error(`Search error ${res.status}`);
    return res.json() as Promise<SearchResponse>;
  },
};
```
