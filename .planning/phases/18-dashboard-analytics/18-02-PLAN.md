# Plan 18-02: Frontend Analytics Page

## Goal

Add an Analytics page to the dashboard with 5 charts/components covering all Phase 18 success criteria.

## Context

- New route: `/analytics` added to `App.tsx`
- New nav item "Analytics" added to `Layout.tsx`
- New API methods added to `apps/dashboard/src/api/client.ts`
- New analytics DTOs added to `client.ts` (mirrors backend `analytics-types.ts`)
- Uses existing Recharts (already installed for TokenUsage/Benchmarks pages)

## Tasks

### Task 1 — Add analytics types and API methods to client.ts

Add to `apps/dashboard/src/api/client.ts`:

```typescript
// Analytics DTOs (mirror packages/dashboard-api/src/routes/analytics-types.ts)
export interface BenchmarkTrendPoint {
  runId: string;
  label?: string;
  timestamp: string;
  mrr: number;
  hitAtK: number;
  avgLatencyMs: number;
  collectionName: string;
  isBaseline: boolean;
}

export interface StrategyComparisonRow {
  collectionName: string;
  runCount: number;
  avgMrr: number;
  avgHitAtK: number;
  avgLatencyMs: number;
}

export interface ScoreBucket {
  label: string;
  bucketStart: number;
  bucketEnd: number;
  count: number;
}

export interface ScoreDistributionEntry {
  collectionName: string;
  buckets: ScoreBucket[];
  totalQueries: number;
}

export interface TokenBreakdownEntry {
  strategy: string;
  totalTokens: number;
  avgTokensPerQuery: number;
  totalQueries: number;
}
```

Add API methods to the `DashboardApi` class:

```typescript
async getAnalyticsBenchmarkTrends(limit = 50): Promise<BenchmarkTrendPoint[]>
async getAnalyticsStrategyComparison(): Promise<StrategyComparisonRow[]>
async getAnalyticsScoreDistribution(): Promise<ScoreDistributionEntry[]>
async getAnalyticsTokenBreakdown(): Promise<TokenBreakdownEntry[]>
```

### Task 2 — Create chart components

Create `apps/dashboard/src/components/analytics/` directory with:

**`BenchmarkTrendChart.tsx`**

- Recharts `ResponsiveContainer > LineChart`
- X axis: `timestamp` (formatted as date)
- Two lines: `mrr` (blue/indigo) and `hitAtK` (green)
- Tooltip showing run label, MRR, Hit@K, latency
- Render nothing / "No data" message if data is empty

**`StrategyComparisonChart.tsx`**

- Recharts `ResponsiveContainer > BarChart`
- X axis: `collectionName`
- Two grouped bars: `avgMrr` (indigo) and `avgHitAtK` (green)
- Tooltip with latency info
- Render "No data" if empty

**`StrategyComparisonTable.tsx`**

- Plain table (Tailwind styled, consistent with HistoryTable)
- Columns: Strategy, Runs, Avg MRR, Avg Hit@K, Avg Latency
- Sortable by any column
- "No benchmark runs" empty state

**`ScoreDistributionChart.tsx`**

- Recharts `ResponsiveContainer > BarChart`
- One chart per strategy (mapped from `ScoreDistributionEntry[]`)
- X axis: bucket labels (0.0–0.1, 0.1–0.2, …)
- Y axis: count
- Each strategy gets a section with a heading

**`TokenBreakdownChart.tsx`**

- Recharts `ResponsiveContainer > BarChart`
- X axis: strategy
- Bars: `totalTokens` (indigo) and `avgTokensPerQuery` (amber) — dual axis
- "No data" empty state

### Task 3 — Create AnalyticsPage.tsx

Create `apps/dashboard/src/pages/AnalyticsPage.tsx`:

```
/analytics
├── Page header: "Analytics"
├── Section: "Benchmark Quality Trends"
│   └── BenchmarkTrendChart (mrr + hitAtK over time)
├── Section: "Strategy Comparison"
│   ├── StrategyComparisonChart (bar chart)
│   └── StrategyComparisonTable (table below chart)
├── Section: "Score Distributions"
│   └── ScoreDistributionChart (one per strategy)
└── Section: "Token Usage by Strategy"
    └── TokenBreakdownChart
```

Layout: uses existing page patterns (px-6 py-8, section headings in text-sm font-semibold uppercase)

Loading states: show spinner/skeleton per section while fetching.

Error states: show inline error message per section if fetch fails (not full-page error).

Empty state: show "No data yet — run `ia-framework benchmark run` to populate analytics" in a subtle callout when all sections are empty.
