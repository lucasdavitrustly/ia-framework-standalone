# Plan 18-01: Backend Analytics Endpoints

## Goal

Expose four analytics API endpoints under `/api/analytics` that aggregate benchmark and metrics data for the frontend charts.

## Context

- Benchmark data: `BenchmarkStore.listRuns()` returns `BenchmarkRun[]` with `mrr`, `hitAtK`, `avgLatencyMs`, `timestamp`, `configSnapshot.collectionName`, `queries[].reciprocalRank`
- Metrics data: `MetricsStore.getStrategyStats()` returns `StrategyStats[]` with `strategy`, `totalTokens`, `avgTokensPerQuery`
- New router `analyticsRouter` wired into `createApp` via `app.route('/api/analytics', analyticsApp)`
- TDD: write tests first, then implement

## Tasks

### Task 1 — Types for analytics response DTOs

Create `packages/dashboard-api/src/routes/analytics-types.ts`:

```typescript
/** Single data point in a benchmark trend chart */
export interface BenchmarkTrendPoint {
  runId: string;
  label?: string;
  timestamp: string;
  mrr: number;
  hitAtK: number;
  avgLatencyMs: number;
  collectionName: string;
  isBaseline: boolean;
}

/** One row in the strategy comparison table */
export interface StrategyComparisonRow {
  collectionName: string;
  runCount: number;
  avgMrr: number;
  avgHitAtK: number;
  avgLatencyMs: number;
}

/** Histogram bucket for score distribution */
export interface ScoreBucket {
  label: string; // e.g. "0.0–0.1"
  bucketStart: number; // e.g. 0.0
  bucketEnd: number; // e.g. 0.1
  count: number;
}

/** Score distribution per strategy */
export interface ScoreDistributionEntry {
  collectionName: string;
  buckets: ScoreBucket[];
  totalQueries: number;
}

/** Token breakdown per strategy */
export interface TokenBreakdownEntry {
  strategy: string;
  totalTokens: number;
  avgTokensPerQuery: number;
  totalQueries: number;
}
```

### Task 2 — Write analytics router tests (TDD)

Create `packages/dashboard-api/src/routes/analytics.test.ts`:

Tests for all 4 endpoints using in-memory mock stores:

1. `GET /api/analytics/benchmark-trends`
   - Returns array of `BenchmarkTrendPoint` sorted by timestamp ASC
   - Empty array when no runs exist
   - Accepts optional `?limit=` query param (default 50)

2. `GET /api/analytics/strategy-comparison`
   - Groups runs by `configSnapshot.collectionName`
   - Returns `StrategyComparisonRow[]` with correct averages
   - Empty array when no runs exist

3. `GET /api/analytics/score-distribution`
   - Bins `reciprocalRank` from all query results into 10 buckets [0, 0.1) ... [0.9, 1.0]
   - Groups by `configSnapshot.collectionName`
   - Returns `ScoreDistributionEntry[]`
   - Empty array when no runs exist

4. `GET /api/analytics/token-breakdown`
   - Returns `TokenBreakdownEntry[]` from metricsStore.getStrategyStats()
   - Empty array when getStrategyStats returns []

All tests should pass before moving to implementation.

### Task 3 — Implement analytics router

Create `packages/dashboard-api/src/routes/analytics.ts`:

```typescript
import { Hono } from 'hono';
import type { BenchmarkRun } from '@ia-framework/benchmark';
import type { StrategyStats } from '@ia-framework/observability';
import type {
  BenchmarkTrendPoint,
  StrategyComparisonRow,
  ScoreDistributionEntry,
  TokenBreakdownEntry,
} from './analytics-types.js';

interface AnalyticsDeps {
  benchmarkStore: {
    listRuns(limit?: number): BenchmarkRun[];
  };
  metricsStore: {
    getStrategyStats(): StrategyStats[];
  };
}

export function analyticsRouter(deps: AnalyticsDeps): Hono {
  const app = new Hono();

  // GET /api/analytics/benchmark-trends
  app.get('/benchmark-trends', (c) => { ... });

  // GET /api/analytics/strategy-comparison
  app.get('/strategy-comparison', (c) => { ... });

  // GET /api/analytics/score-distribution
  app.get('/score-distribution', (c) => { ... });

  // GET /api/analytics/token-breakdown
  app.get('/token-breakdown', (c) => { ... });

  return app;
}
```

Implementation notes:

- `benchmark-trends`: `listRuns(limit)` → sort by timestamp ASC → map to `BenchmarkTrendPoint`
- `strategy-comparison`: group by `configSnapshot.collectionName`, compute averages
- `score-distribution`: iterate all runs → for each run's queries, bucket `reciprocalRank` into 10 bins; group buckets by collectionName
- `token-breakdown`: `getStrategyStats()` → map to `TokenBreakdownEntry`

### Task 4 — Wire analyticsRouter into createApp
