  <files>docker-compose.yml, docker-compose.override.yml, .env.example, scripts/qdrant-health.sh</files>
  <action>
    **docker-compose.yml** — production-like Qdrant configuration:
    ```yaml
    services:
      qdrant:
        image: qdrant/qdrant:latest
        container_name: ia-framework-qdrant
        restart: unless-stopped
        ports:
          - "${QDRANT_HTTP_PORT:-6333}:6333"
          - "${QDRANT_GRPC_PORT:-6334}:6334"
        volumes:
          - qdrant_data:/qdrant/storage
        environment:
          QDRANT__SERVICE__GRPC_PORT: "6334"
          QDRANT__LOG_LEVEL: INFO
        ulimits:
          nofile:
            soft: 65536
            hard: 65536
        healthcheck:
          test: ["CMD-SHELL", "curl -f http://localhost:6333/health || exit 1"]
          interval: 30s
          timeout: 10s
          retries: 5
          start_period: 10s

    volumes:
      qdrant_data:
        name: ia-framework-qdrant-data
    ```

    Note on ulimits: Qdrant recommends setting `nofile` limits to at least 65536 for production workloads. Required for large codebases.

    **docker-compose.override.yml** — development overrides (not committed if sensitive, but this one is safe to commit):
    ```yaml
    # Development overrides — auto-loaded by docker compose
    # Adds dashboard service (Phase 8) and other dev services later
    services:
      qdrant:
        # In dev, use verbose logging
        environment:
          QDRANT__LOG_LEVEL: DEBUG
    ```

    **.env.example** — template developers copy to .env:
    ```bash
    # ia-framework environment configuration
    # Copy this file to .env and fill in your values
    # .env is gitignored — never commit secrets

    QDRANT_HTTP_PORT=6333
    QDRANT_GRPC_PORT=6334

    # OpenAI embedding (if using cloud embeddings)

    # Target project (can also be set in .ia-framework/project.json)
    # TARGET_PROJECT_PATH=/path/to/your/project
    ```

    **scripts/qdrant-health.sh** — quick manual health check:
    ```bash
    #!/usr/bin/env bash
    set -euo pipefail

    QDRANT_URL="${QDRANT_URL:-http://localhost:6333}"

    echo "Checking Qdrant health at $QDRANT_URL..."
    response=$(curl -sf "$QDRANT_URL/health" 2>&1) || {
      echo "ERROR: Qdrant is not responding at $QDRANT_URL"
      echo "Try: docker compose up -d qdrant"
      exit 1
    }

    echo "Qdrant is healthy: $response"
    echo ""
    echo "Collections:"
    curl -sf "$QDRANT_URL/collections" | python3 -m json.tool 2>/dev/null || echo "(none yet)"
    ```

    Make script executable: `chmod +x scripts/qdrant-health.sh`

    Ensure scripts/ directory is created. Verify docker compose config parses correctly.
