When processing a `class_declaration` or `abstract_class_declaration` (or its parent `export_statement`), check if the node or its wrapper has `decorator` children. In the TypeScript tree-sitter grammar, decorators are child nodes of the declaration (not siblings). They appear as `decorator` type nodes before the class keyword.

For top-level declarations wrapped in `export_statement`:

```typescript
// After: const startLine = child.startPosition.row + 1;
// Check if the export_statement or declaration has decorator children
let decoratorStartLine = startLine;
const decorators = child.children.filter((c) => c.type === 'decorator');
if (decorators.length > 0) {
  decoratorStartLine = decorators[0].startPosition.row + 1;
}
// Also check targetNode for decorators (when not exported)
const targetDecorators = targetNode.children.filter((c) => c.type === 'decorator');
if (targetDecorators.length > 0 && targetDecorators[0].startPosition.row + 1 < decoratorStartLine) {
  decoratorStartLine = targetDecorators[0].startPosition.row + 1;
}
// Use Math.min(decoratorStartLine, startLine) for content extraction
const effectiveStartLine = Math.min(decoratorStartLine, startLine);
const content = lines.slice(effectiveStartLine - 1, endLine).join('\n');
```

   ````markdown
   ## GOOD boundary example: Spring AOP @Aspect class kept as single chunk

   Input source (lines 1-25):

   ```java
    1: @Aspect
    2: @Component
    3: public class AuditAspect {
    4:
    5:     @Around("execution(* com.example.service.*.*(..))")
    6:     public Object auditServiceCall(ProceedingJoinPoint jp) throws Throwable {
    7:         long start = System.currentTimeMillis();
    8:         Object result = jp.proceed();
    9:         long elapsed = System.currentTimeMillis() - start;
   10:         log.info("Method {} took {}ms", jp.getSignature().getName(), elapsed);
   11:         return result;
   12:     }
   13:
   14:     @Before("@annotation(com.example.Auditable)")
   15:     public void beforeAuditable(JoinPoint jp) {
   16:         log.info("Entering auditable method: {}", jp.getSignature());
   17:     }
   18: }
   ```
   ````

   Correct chunking output:

   ```json
   {
     "chunks": [
       {
         "startLine": 1,
         "endLine": 18,
         "summary": "Implements AOP audit aspect that logs execution time for all service methods and records entry for @Auditable-annotated methods via Spring pointcut expressions"
       }
     ]
   }
   ```

   Why: The @Aspect class, its @Around and @Before advice, and the pointcut expressions form a single cross-cutting concern. Splitting advice methods into separate chunks loses the relationship between the aspect declaration and the join point interception logic.
