3. In `packages/ast-parser/src/parsers/java.ts`, modify `collectDeclarations()`:

   a. **Annotation inclusion for methods:** Before creating a method chunk, scan backward from the method node through preceding siblings in `class_body`. Collect all consecutive `marker_annotation` and `annotation` nodes that immediately precede the method. Extend `startLine` upward to include them and prepend annotation text to `rawContent`.

   Specifically, inside the `for (const child of node.children)` loop, when `isMember` is true:

   ```typescript
   // Collect preceding annotation siblings
   let annotationStartLine = startLine;
   const siblingIndex = Array.from(node.children).indexOf(child);
   for (let i = siblingIndex - 1; i >= 0; i--) {
     const prev = node.children[i];
     if (prev.type === 'marker_annotation' || prev.type === 'annotation') {
       annotationStartLine = prev.startPosition.row + 1;
     } else if (prev.type === 'modifiers') {
       // modifiers node contains annotations in some grammar versions
       annotationStartLine = prev.startPosition.row + 1;
     } else {
       break; // Stop at first non-annotation sibling
     }
   }
   // Use annotationStartLine instead of startLine for content extraction
   const rawContent = sourceLines.slice(annotationStartLine - 1, endLine).join('\n');
   ```

   b. **@Aspect class detection:** In the top-level class handling, check if the class has `@Aspect` annotation. If yes:
   - Emit the entire class as a single chunk with `chunkType: 'aspect'`
   - Do NOT recurse into class body for member extraction

   Detection: check `modifiers` child of `class_declaration` for annotation children containing text "Aspect":

   ```typescript
   function hasAspectAnnotation(classNode: Parser.SyntaxNode): boolean {
     const modifiers =
       classNode.childForFieldName('modifiers') ??
       classNode.children.find((c) => c.type === 'modifiers');
     if (!modifiers) return false;
     return modifiers.children.some(
       (c) =>
         (c.type === 'marker_annotation' || c.type === 'annotation') && c.text.includes('Aspect'),
     );
   }
   ```

   c. **buildPreamble for @Aspect methods:** When emitting method chunks from an `@Aspect` class (only happens if aspect class is large enough to split), include the class-level annotations in the preamble. Modify `buildPreamble()` to accept an optional `includeClassAnnotations: boolean` parameter. When true, prepend annotation lines from the enclosing node's `modifiers` child before the class signature line.

4. Update `makeChunkId` calls to use the new `annotationStartLine` for consistent IDs.
