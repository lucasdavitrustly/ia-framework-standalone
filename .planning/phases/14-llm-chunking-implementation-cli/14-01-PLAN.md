<objective>
Extend core types and pipeline to support LLM chunking data flow.

Purpose: CodeChunk needs a `description` field to carry LLM prose summaries through the pipeline, a `'semantic'` chunk type for LLM-produced chunks, and the config schema needs an `llm` section for chunking model settings. The pipeline's embedding step must use `chunk.description` (when present) instead of `chunkToDescription()` for text vectors — this is the key quality differentiator of LLM chunking (per D-03, D-04).

Output: Extended types, config schema, and description-aware pipeline ready for LlmChunkingStrategy in Plan 02.
</objective>
