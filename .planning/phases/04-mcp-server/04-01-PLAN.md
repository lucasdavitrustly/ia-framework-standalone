<objective>
Create the `packages/retrieval` package — the semantic search engine that sits between the MCP server and Qdrant. It takes a natural language query, embeds it using the configured provider, searches both 'text' and 'code' named vectors in Qdrant, deduplicates and merges results by max-score, and returns ranked RetrievalResult[].

Purpose: The MCP server (Plan 04-02) needs a clean retrieval API to call. This package is that API.
Output: `@ia-framework/retrieval` package with `SearchEngine` class exposing `search()` and `getFile()`.
</objective>

interface SearchOptions {

<!-- Retrieval package's own types -->
```typescript
interface RetrievalQuery {
  text: string;                   // natural language query
  limit?: number;                 // max results (default 10)
  scoreThreshold?: number;        // min score (default 0.5)
  filter?: Record<string, unknown>; // optional Qdrant filter
}

interface RetrievalResult {
  chunkId: string;               // original chunk ID (sha1)
  filePath: string;
  relativePath: string;
  language: string;
  chunkType: string;
  name?: string | undefined;
  content: string;
  startLine: number;
  endLine: number;
  imports: string[];
  exports: string[];
  score: number;                 // best score across text+code vectors
  matchedVector: 'text' | 'code' | 'both'; // which vector(s) matched
}

interface SearchEngineConfig {
  embeddingProvider: EmbeddingProvider;
  vectorStore: VectorStore;
  defaultLimit?: number;
  defaultScoreThreshold?: number;
}
```

<!-- Merge strategy -->
- Search both 'text' and 'code' vectors with limit * 2 each
- Deduplicate by payload.chunkId
- For duplicates, take the higher score; set matchedVector='both'
- Sort by score descending, return top `limit` results
- Return RetrievalResult[] (mapped from ChunkPayload + score)
