  <action>
    1. Add `compareSubcommand()` to `prompt.command.ts`:
       ```typescript
       function compareSubcommand(): Command {
         return new Command('compare')
           .description('Compare two prompt versions: full re-index + benchmark for each, then diff')
           .argument('<v1>', 'First prompt version number')
           .argument('<v2>', 'Second prompt version number')
           .option('-c, --config <path>', 'Path to project.json config')
           .option('--corpus <path>', 'Path to benchmark-queries.json')
           .option('-o, --output <path>', 'Output path for markdown report')
           .action(async (v1Str, v2Str, options) => { ... })
       }
       ```

    2. Implementation flow inside action:
       a. Parse v1, v2 as integers. Validate both >= 1.
       b. Load config, corpus (same pattern as benchmark run command).
       c. For each version (v1, then v2):
          - Display: `\n◆ Testing prompt version ${version}...`
          - Temporarily set promptVersion in config object (in memory, not on disk)
          - Run full indexing pipeline programmatically (import from @ia-framework/indexer or invoke via CLI subprocess)
          - Run benchmark using BenchmarkRunner.run() (same as benchmark run command)
          - Store the BenchmarkRun result
       d. After both versions complete, display comparison.

    3. For programmatic indexing: Check how `index` CLI command triggers indexing. Import the indexing function and call it with modified config. If direct import isn't available, use `execSync` or `spawn` to call `ia-framework index --config ... --prompt-version N` as a subprocess. The subprocess approach is simpler and avoids import complexity.

       Subprocess approach:
       ```typescript
       import { execFileSync } from 'node:child_process';
       // For each version:
       execFileSync(process.argv[0]!, [process.argv[1]!, 'index', '-c', configPath, '--force'], {
         stdio: 'inherit',
         env: { ...process.env, IA_PROMPT_VERSION: String(version) }
       });
       ```
       Or modify project.json temporarily on disk, index, then restore. Per D-15, full re-index is required.

       Simplest reliable approach: write promptVersion to config file, run index, then restore. This guarantees the indexer sees the correct version.

    4. Display results as console table per D-13:
       ```
       Prompt Comparison: v{v1} vs v{v2}

       ┌─────────────────────────┬──────────┬──────────┬─────────┐
       │ Query                   │ MRR-v{v1}│ MRR-v{v2}│ Delta   │
       ├─────────────────────────┼──────────┼──────────┼─────────┤
       │ {query text}            │ 0.50     │ 1.00     │ +0.50   │ (green)
       │ {query text}            │ 1.00     │ 0.33     │ -0.67   │ (red)
       └─────────────────────────┴──────────┴──────────┴─────────┘

       Summary:
         v{v1} MRR: 0.55 | v{v2} MRR: 0.68 | Delta: +0.13
       ```

       Color coding: Use ANSI escape codes — `\x1b[32m` for green (positive delta), `\x1b[31m` for red (negative delta), `\x1b[0m` to reset.

    5. Save markdown report per D-13:
       - Default path: `.ia-framework/prompt-compare-v{v1}-v{v2}-{timestamp}.md`
       - Override via `--output` flag
       - Content: same table in markdown format (no ANSI colors), plus metadata (timestamp, config, corpus path)

    6. Register `compareSubcommand()` in `promptCommand()`:
       ```typescript
       prompt.addCommand(compareSubcommand());
       ```

    7. Restore original promptVersion in config file after comparison completes (in a finally block to handle errors).
