  </behavior>
  <action>
    1. Create `packages/indexer/src/strategies/quality-scorer.ts`:

    ```typescript
    export interface SummaryQualityScore {
      score: number; // 0-100
      checks: {
        lengthScore: number;      // 0-25: min 20 chars for any points, 50+ chars for full marks
        codeTokenScore: number;   // 0-25: penalize camelCase/snake_case identifiers
        purposeVerbScore: number; // 0-25: presence of handles/validates/orchestrates/manages/transforms/routes/provides/implements/configures/processes
        syntaxPenalty: number;    // 0-25: penalize "takes X and returns Y" / "this function" patterns
      };
    }

    export function scoreChunkSummary(summary: string): SummaryQualityScore
    ```

    2. Implementation details:
       - **lengthScore (0-25):** 0 for empty, 5 for <20 chars, 15 for 20-49 chars, 25 for 50+ chars
       - **codeTokenScore (0-25):** Count tokens matching `[a-z][a-zA-Z]+[A-Z]` (camelCase) or `[a-z]+_[a-z]+` (snake_case). 25 if 0 tokens, 15 if 1-2, 5 if 3-5, 0 if 6+
       - **purposeVerbScore (0-25):** Check for verbs: handles, validates, orchestrates, manages, transforms, routes, provides, implements, configures, processes, creates, defines, exports, initializes. 25 if 2+, 15 if 1, 0 if none
       - **syntaxPenalty (0-25):** 25 (no penalty) normally. 0 if contains "this function takes" or "takes .* and returns" or "accepts .* parameter". 10 if contains just "returns" without a purpose verb

    3. `score = lengthScore + codeTokenScore + purposeVerbScore + syntaxPenalty`

    4. Write comprehensive tests covering all score ranges.

  </action>
