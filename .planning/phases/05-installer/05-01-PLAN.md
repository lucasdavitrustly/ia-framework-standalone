<objective>
Create the `install.sh` one-shot installer script that takes a developer from git clone to a configured, running ia-framework instance.

The installer must:
1. Detect which prerequisites are missing (Docker, Node.js >=22, Ollama, OpenCode)
2. Auto-install missing tools (platform-aware: macOS via Homebrew, Linux via system package manager)
3. Skip tools already installed
4. Ask for target project path if not already configured
5. Start Qdrant Docker container via docker compose
6. Run `pnpm install && pnpm build` to compile the framework
7. Print a success summary with next steps

Purpose: Frictionless first-run experience — clone → one command → working.
Output: `install.sh` + helper scripts in `scripts/`.
</objective>

    **scripts/check-prerequisites.sh**: Sources the other scripts. Functions:
    - `check_docker()` → prints "INSTALLED" or "MISSING"
    - `check_node()` → checks `node --version` >= 22.0.0, prints "INSTALLED" or "MISSING (found X.Y.Z)"

    - macOS: `brew install node@22 && brew link node@22 --force --overwrite`

    **scripts/install-opencode.sh**: Function `install_opencode()`:
    - Install via npm: `npm install -g @opencode-sh/opencode`
    - After install, verify `opencode --version` works

  <files>scripts/start-services.sh, scripts/init-config.sh</files>
  <action>
    **scripts/start-services.sh**: Function `start_qdrant()`:
    - Run `docker compose up -d qdrant` from the ia-framework directory
    - Wait for Qdrant health: poll `curl -sf http://localhost:6333/readyz` up to 30 times (1s interval)
    - Print success when ready, fail with timeout message if not ready after 30s
    - Idempotent: if already running, print "already running" and return 0

    **scripts/init-config.sh**: Function `init_config()`:
    - Check if `.ia-framework/project.json` already exists
    - If exists: print "Config found at .ia-framework/project.json — skipping init" and return
    - If missing: prompt user "Enter the absolute path to your target project: "
    - Validate path exists (is a directory)
    - Write default `.ia-framework/project.json` with targetProjectPath set
    - Print config location

    The config written by init_config() must match the ProjectConfigSchema from @ia-framework/core.
  </action>

<task type="auto">
  <name>Task 3: Main install.sh entrypoint</name>
  <files>install.sh</files>
  <action>
    Create the main `install.sh` entrypoint:

    ```bash
    #!/usr/bin/env bash
    set -euo pipefail

    # Colors
    RED='\033[0;31m'; GREEN='\033[0;32m'; YELLOW='\033[1;33m'; BLUE='\033[0;34m'; NC='\033[0m'

    # Resolve script directory (handles symlinks)
    SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"

    # Source helpers
    source "${SCRIPT_DIR}/scripts/check-prerequisites.sh"
    source "${SCRIPT_DIR}/scripts/install-docker.sh"
    source "${SCRIPT_DIR}/scripts/install-node.sh"
    source "${SCRIPT_DIR}/scripts/install-ollama.sh"
    source "${SCRIPT_DIR}/scripts/install-opencode.sh"
    source "${SCRIPT_DIR}/scripts/start-services.sh"
    source "${SCRIPT_DIR}/scripts/init-config.sh"

    echo -e "${BLUE}╔══════════════════════════════════╗${NC}"
    echo -e "${BLUE}║  ia-framework installer v0.1.0   ║${NC}"
    echo -e "${BLUE}╚══════════════════════════════════╝${NC}"
    echo ""

    # Step 1: Check & install prerequisites
    echo -e "${YELLOW}→ Checking prerequisites...${NC}"
    
    [check and install each tool: docker, node, ollama, opencode]
    [skip if already installed, install if missing]

    # Step 2: Build the framework
    echo -e "${YELLOW}→ Building ia-framework...${NC}"
    cd "${SCRIPT_DIR}"
    pnpm install --frozen-lockfile
    pnpm build
    
    # Step 3: Initialize config (ask for target project path if needed)
    init_config

    # Step 4: Start services (Qdrant)
    echo -e "${YELLOW}→ Starting services...${NC}"
    start_qdrant

    # Step 5: Pull embedding model
    echo -e "${YELLOW}→ Pulling embedding model (nomic-embed-text)...${NC}"
    ollama pull nomic-embed-text

    # Step 6: Print success summary
    echo ""
    echo -e "${GREEN}✓ Installation complete!${NC}"
    echo ""
    echo "Next steps:"
    echo "  1. Index your codebase:  pnpm --filter @ia-framework/cli ia-framework index"
    echo "  2. Or use the CLI:       node packages/cli/dist/bin.js index"
    echo "  3. Configure OpenCode:   see docs/opencode-setup.md"
    ```

    Make the script executable with `chmod +x install.sh`.
