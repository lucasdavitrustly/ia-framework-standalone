    **6. Create spike/llm-chunking/src/chunker.ts:**

    Export async function `chunkFile(params: { filePath: string; content: string; fileName: string; model: string; baseUrl?: string; numCtx?: number }): Promise<ChunkingResult>`:
    - Estimate tokens: `Math.ceil(content.length / 4)` (existing pattern)
    - Compute `maxSourceTokens = Math.floor((params.numCtx ?? 32768) * 0.9)` (per D-23: 90% for source, 10% for prompt+response)
    - If `estimatedTokens < maxSourceTokens`: call `generateChunks()` with `buildPrompt(content, fileName)` directly
    - If `estimatedTokens >= maxSourceTokens`: call `chunkFileWithWindowing()`

    Export async function `chunkFileWithWindowing(params: { filePath: string; content: string; fileName: string; model: string; baseUrl?: string; numCtx?: number; overlapLines?: number }): Promise<ChunkingResult>`:
    - Split `content` into lines
    - Compute `maxCharsPerWindow = maxSourceTokens * 4` (reverse of token estimation)
    - Split lines into windows where each window's total characters ≤ `maxCharsPerWindow`
    - Split on line boundaries (never mid-line)
    - Overlap: `params.overlapLines ?? 20` lines between consecutive windows (per D-24, default 20)
    - For each window: call `generateChunks()` with `buildPrompt(windowContent, fileName)`
    - Adjust returned `startLine`/`endLine` to be relative to the full file (add window offset)
    - Stitch results (per D-25):
      - Sort all chunks by `startLine`
      - If chunk A's `endLine >= chunk B's startLine` (overlap from adjacent windows):
        - Merge: `startLine = min(A.startLine, B.startLine)`, `endLine = max(A.endLine, B.endLine)`
        - Summary: use the one from the window where the chunk was fully contained (not split by window boundary)
      - Deduplicate any exact duplicate chunks
    - Aggregate metrics: sum `totalDurationMs`, sum tokens, recompute `tokensPerSec` from totals
    - Return merged `ChunkingResult`
