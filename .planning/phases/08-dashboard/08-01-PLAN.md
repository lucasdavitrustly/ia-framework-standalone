  <behavior>
    <!-- API contract — all routes return JSON -->

    GET /api/status
    - Returns: { qdrant: 'ok' | 'error', indexingInProgress: boolean, lastIndexedCommit: string | null, timestamp: string }
    - Calls QdrantClient GET /readyz to check health; sets qdrant='error' on failure (does NOT throw)
    - Reads lastIndexedCommit from frameworkDir/.ia-framework-commit (same file as incremental.ts uses)

    GET /api/config
    - Returns: ProjectConfig from in-memory ConfigWatcher cache
    - 200 with config JSON on success; 503 with { error: 'Config not loaded' } if cache is empty

    GET /api/metrics
    - Returns: { totals: TotalStats, byStrategy: StrategyStats[], byDay: DailyTokenUsage[] }
    - DailyTokenUsage: { date: string (YYYY-MM-DD), totalTokens: number, totalQueries: number }
    - byDay computed by grouping rag_events by ISO date of timestamp field

    GET /api/metrics/events
    - Query params: limit (default 50), offset (default 0)
    - Returns: { events: RagEvent[], total: number }
    - Events ordered by timestamp DESC (newest first)
    - Supports pagination for the per-query detail view

    GET /api/benchmarks
    - Query params: limit (default 20)
    - Returns: { runs: BenchmarkRun[] } — full run objects including queries array

    GET /api/benchmarks/:runId
    - Returns: BenchmarkRun with full queries array; 404 with { error: 'Run not found' } if unknown

    GET /api/indexing/status
    - Returns: IndexingState — current in-memory progress snapshot
    - IndexingState: { running: boolean, stage: string | null, filesTotal: number, filesProcessed: number, chunksTotal: number, chunksIndexed: number, currentFile: string | null, startedAt: string | null, completedAt: string | null, error: string | null }

    POST /api/indexing/trigger
    - Body (JSON): { incremental?: boolean, label?: string }
    - If already running: 409 with { error: 'Indexing already in progress' }
    - Starts IndexingPipeline.run() in background (do NOT await — fire and forget, update state via ProgressCallback)
    - Returns immediately: 202 with { message: 'Indexing started', startedAt: string }

    <!-- ConfigWatcher behavior -->
    ConfigWatcher:
    - constructor(configPath: string): starts chokidar.watch(configPath, { persistent: false })
    - On 'change' event: calls loadConfig(configPath), updates internal cache, emits 'updated' event
    - getConfig(): ProjectConfig | null — returns current in-memory config (null if not yet loaded)
    - start(): Promise<void> — triggers initial load synchronously before watching
    - stop(): void — calls watcher.close()

    <!-- IndexingStateManager behavior -->
    IndexingStateManager:
    - getState(): IndexingState — always returns current snapshot (defaults all to null/false/0)
    - start(startedAt: string): void — sets running=true, resets all counters and error
    - update(progress: IndexingProgress): void — copies stage/filesTotal/filesProcessed/chunksTotal/chunksIndexed/currentFile from progress
    - complete(completedAt: string): void — sets running=false, stage='done', completedAt
    - fail(error: string): void — sets running=false, error message, completedAt=now

    ## Step 3 — ConfigWatcher (src/config-watcher.ts)

    Uses chokidar + loadConfig:
    ```typescript
    import chokidar from 'chokidar';
    import { loadConfig } from '@ia-framework/core';
    import type { ProjectConfig } from '@ia-framework/core';
    import { EventEmitter } from 'node:events';

    export class ConfigWatcher extends EventEmitter {
      private config: ProjectConfig | null = null;
      private watcher: chokidar.FSWatcher | null = null;

      constructor(private readonly configPath: string) { super(); }

      async start(): Promise<void> {
        // Initial load
        this.config = await loadConfig(this.configPath);
        // Watch for changes
        this.watcher = chokidar.watch(this.configPath, { persistent: false });
        this.watcher.on('change', async () => {
          try { this.config = await loadConfig(this.configPath); this.emit('updated', this.config); }
          catch { /* log but don't crash */ }
        });
      }

      getConfig(): ProjectConfig | null { return this.config; }
      stop(): void { this.watcher?.close(); }
    }
    ```

    ## Step 6 — Server entry (src/server.ts)

    Wires all real dependencies together. NOT tested (integration-level). Called via `tsx src/server.ts` in dev or `node dist/server.js` in production:

    ```typescript
    export interface ServerOptions {
      port: number;
      frameworkDir: string;
      configPath: string;
      publicDir: string;
    }

    export async function startServer(options: ServerOptions): Promise<void> {
      const configWatcher = new ConfigWatcher(options.configPath);
      await configWatcher.start();

      const config = configWatcher.getConfig()!;
      const metricsStore = new MetricsStore(join(options.frameworkDir, 'metrics.sqlite'));
      const benchmarkStore = new BenchmarkStore(join(options.frameworkDir, 'benchmarks.sqlite'));
      const indexingState = new IndexingStateManager();
      const embeddingProvider = createEmbeddingProvider(config.embedding);
      const vectorStore = new QdrantVectorStore({ ... });
      const indexingPipeline = new IndexingPipeline();

      const app = createApp({ metricsStore, benchmarkStore, configWatcher, indexingState, indexingPipeline, projectConfig: config, frameworkDir: options.frameworkDir, qdrantHost: config.vectorStore.host, qdrantPort: config.vectorStore.port });

      // Serve static files for React build
      process.env['DASHBOARD_PUBLIC_DIR'] = options.publicDir;

      const port = options.port;
      serve({ fetch: app.fetch, port }, () => { console.log(`Dashboard API running on http://localhost:${port}`); });

      // Graceful shutdown
      process.on('SIGTERM', () => { configWatcher.stop(); metricsStore.close(); benchmarkStore.close(); process.exit(0); });
    }
    ```

    Read port and paths from env vars with defaults:
    - `DASHBOARD_PORT` (default: 3000)
    - `IA_FRAMEWORK_DIR` (required — fail with error if missing)
    - `IA_FRAMEWORK_CONFIG` (default: `join(IA_FRAMEWORK_DIR, 'project.json')`)
    - `DASHBOARD_PUBLIC_DIR` (default: `join(import.meta.dirname, '../public')`)
