    11. searchKeyword gracefully degrades: if vectorStore.searchKeyword is undefined, skip keyword step and return empty suggestions
    12. searchHybrid gracefully degrades: if vectorStore.searchHybrid is undefined, skip hybrid step and go straight to keyword

    Step 2: Add `searchWithFallback()` to SearchEngine
    - Method signature: `async searchWithFallback(query: RetrievalQuery, options?: { enableFallback?: boolean; maxSuggestions?: number }): Promise<FallbackSearchResult>`
    - Sequence:
      1. Call `this.search(query)` (primary semantic with user threshold)
      2. If results.length > 0 → return `{ found: true, fallback_used: false, fallback_mode: 'none', results, suggestions: [] }`
      3. If results.length === 0 AND enableFallback !== false:
         a. If vectorStore.searchHybrid exists → call `this.searchHybrid({ ...query, scoreThreshold: undefined })` (hybrid uses no threshold per engine defaults)
         b. If hybrid results.length > 0 → return `{ found: true, fallback_used: true, fallback_mode: 'hybrid', results: hybridResults, suggestions: [] }`
         c. If still 0 AND vectorStore.searchKeyword exists → call `vectorStore.searchKeyword({ sparseVector: computeTermFrequencySparseVector(query.text), limit: maxSuggestions ?? 3 })`
         d. Map keyword results to suggestions: `{ file: r.payload.relativePath, name: r.payload.name ?? r.payload.chunkType, snippet: r.payload.content.slice(0, 200) }`
         e. Return `{ found: false, fallback_used: true, fallback_mode: 'keyword', results: [], suggestions }`
      4. If enableFallback === false and no results → return `{ found: false, fallback_used: false, fallback_mode: 'none', results: [], suggestions: [] }`
