## Architecture Constraints (already decided — do not revisit)

- db.json path convention: always `join(frameworkDir, 'db.json')`
- MCP tools gracefully return "Database not configured" if db.json missing — no crash
- CLI `db configure` is interactive prompts that write db.json
- Dashboard DB card is neutral gray when not configured (no red error state)
- `PostgresSource` and `loadDbConfig` imported from `@ia-framework/db-context`
- Full TDD throughout — test handlers in isolation, mock PostgresSource

**New file: `packages/mcp-server/src/tools/query-database.ts`**

```ts
// Handler + registration for the query_database MCP tool.
// Executes arbitrary SQL against the configured PostgreSQL database.
// Loaded from db.json (join(frameworkDir, 'db.json')).
// Gracefully returns error text if db.json is missing or connection fails.
```

Handler signature:
```ts
export async function queryDatabaseHandler(
  input: { sql: string },
  dbConfigPath: string,
): Promise<ToolOutput>
```

Implementation:
1. Try `loadDbConfig(dbConfigPath)` — if `DbConfigNotFoundError`, return text: `"Database not configured. Run: ia-framework db configure"`
2. Create `new PostgresSource(config)`, call `executeQuery(input.sql)`, then `close()`
3. On success: return `JSON.stringify(result.rows, null, 2)` as text, prepended with `Rows: ${result.rowCount}\n\n`
4. On any other error: return the error message as text (no throw)
5. Tool description must include: `"WARNING: This tool executes SQL directly. Write operations (INSERT, UPDATE, DELETE) will modify the database."`

Registration function:
```ts
export function registerQueryDatabaseTool(server: McpServer, dbConfigPath: string): void
```

Zod schema for input: `{ sql: z.string().min(1).describe("SQL query to execute") }`

**New file: `packages/mcp-server/src/tools/index-database-schema.ts`**

```ts
// Handler + registration for the index_database_schema MCP tool.
// Triggers IndexingPipeline with PostgresSource to embed DB schema into Qdrant.
// Requires both project.json and db.json to be present.
```

Handler signature:
```ts
export async function indexDatabaseSchemaHandler(
  configPath: string,
  dbConfigPath: string,
): Promise<ToolOutput>
```

Implementation:
1. Try `loadConfig(configPath)` — if `ConfigNotFoundError`, return text: `"No project configured."`
2. Try `loadDbConfig(dbConfigPath)` — if `DbConfigNotFoundError`, return text: `"Database not configured. Run: ia-framework db configure"`
3. Create `PostgresSource`, `EmbeddingProvider`, `QdrantVectorStore`, `IndexingPipeline`
4. Run pipeline with:
   ```ts
   {
     targetProjectPath: config.targetProjectPath,
     frameworkDir: dirname(configPath),
     collectionName: config.vectorStore.collectionName,
     embeddingProvider,
     vectorStore,
     contextSources: [postgresSource],
     includePatterns: [],   // skip file-based indexing in this tool
     excludePatterns: ['**/*'],
   }
   ```
5. Call `postgresSource.close()` after pipeline completes
6. Return text: `"Indexed {chunksIndexed} database schema chunks into Qdrant."`
7. On error: return error message as text (no throw)

Registration function:
```ts
export function registerIndexDatabaseSchemaTool(server: McpServer, configPath: string, dbConfigPath: string): void
```

No input schema (tool takes no user inputs — paths come from server config).

### Task 2 — CLI `ia-framework db` subcommand
`type="auto" tdd="true"`

**New file: `packages/cli/src/commands/db.command.ts`**

Top-level structure:
```ts
export function dbCommand(): Command {
  const cmd = new Command('db').description('Database context commands');
  cmd.addCommand(configureSubcommand());
  cmd.addCommand(connectSubcommand());
  cmd.addCommand(indexSubcommand());
  cmd.addCommand(statusSubcommand());
  return cmd;
}
```

**`configure` subcommand:**
- Uses `readline` (Node.js built-in) for interactive prompts — no external deps
- Prompts: host (default: localhost), port (default: 5432), database name, user, password (no echo), ssl? (y/N)
- Validates with `DatabaseConfigSchema.parse()` — re-prompts on validation failure
- Writes to `join(frameworkDir, 'db.json')` as pretty JSON (indent: 2)
- Prints: `✓ Database config saved to .ia-framework/db.json`

**`connect` subcommand:**
- Loads db.json via `loadDbConfig()` — prints "Not configured. Run: ia-framework db configure" if missing
- Creates `PostgresSource`, calls `testConnection()`, then `close()`
- On success: prints `✓ Connected to {config.database}@{config.host}:{config.port} — {tableCount} tables found`
- On failure: prints `✗ Connection failed: {error message}`, exits code 1

**`index` subcommand:**
- Loads both project.json and db.json
- Creates PostgresSource + IndexingPipeline
- Runs pipeline with `contextSources: [postgresSource]` and `includePatterns: [], excludePatterns: ['**/*']` (schema only, no files)
- Shows progress: `Indexing database schema...` then `✓ Indexed {n} schema chunks`
- Calls `postgresSource.close()` after completion

**`status` subcommand:**
- Loads db.json — if missing, prints "Database: not configured"
- If present, calls `testConnection()` then `close()`
- Prints:
  ```
  Database: configured
  Connection: ✓ connected  (or ✗ failed)
  Tables: 42
  Config: {host}:{port}/{database} (user: {user})
  ```
- Never exits non-zero (status is read-only informational)

**Modify `packages/cli/src/bin.ts`:**
```ts
import { dbCommand } from './commands/db.command.js';
// ...
program.addCommand(dbCommand());
```
