# Milestone v1.5: RAG Retrieval Quality Improvements

**Status:** ✅ SHIPPED 2026-05-15
**Phases:** 32, 37–39
**Total Plans:** 5

## Overview

Eliminate context pollution causing MCP to be a net negative. A/B benchmark showed RAG injecting irrelevant context on negative queries and inflating token usage. This milestone added score thresholds, query classification, line-number-aware output, and confidence-based early exit to fix keyword regressions and reduce hallucination.

## Milestone Summary

**Key Decisions:**

- Deterministic heuristic classification (no LLM calls) for query routing — <5ms latency
- Confidence threshold 0.8 for early exit — conservative to avoid false skips
- Score threshold 0.5 as default with configurable override per project

**Issues Resolved:**

- -3pt keyword regression from v1.4 benchmark eliminated
- Hallucination on negative queries fixed via score threshold null fallback

**Technical Debt Incurred:**

- Phases 33-36 (reranking-layer, context-budget-caps, index-code-patterns) from original plan reconceived — partially addressed in v1.6 via different approach
