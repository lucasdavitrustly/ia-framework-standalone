<summary>✅ v1.3 RAG Quality Improvements (Phases 22-27) — SHIPPED 2026-04-29</summary>

**Milestone Goal:** Improve RAG retrieval quality and benchmark scores based on findings from the 2026-04-24 benchmark run on a Java/Spring Boot payment gateway codebase.

- [x] **Phase 22: AST-aware Java Semantic Chunking** — Replace fixed-size Java chunking with web-tree-sitter AST-aware chunking at class/method boundaries (completed 2026-04-28)
- [x] **Phase 23: Zero-result Fallback Search Strategy** — Automatic semantic → hybrid → BM25 fallback + "did you mean?" suggestions when semantic search returns 0 results (completed 2026-04-28)
- [x] **Phase 24: Maven Multi-module Dependency Graph Traversal** — Parse pom.xml files, build module dependency graph, expose `get_module_dependencies` MCP tool (completed 2026-04-28)
- [x] **Phase 25: RAG-to-action Prompt Templates** — Structured prompt templates injected for impact/change-analysis query patterns (completed 2026-04-28)
- [x] **Phase 26: Hallucination Penalty Calibration** — Hallucination Check dimension in benchmark judge; zero score for responses asserting non-existent entities (completed 2026-04-29)
- [x] **Phase 27: Benchmark Executor Model Lock Enforcement** — Validate LLM-IDENTITY block after each run; `--strict-model` flag and `validate-models` subcommand (completed 2026-04-29)
