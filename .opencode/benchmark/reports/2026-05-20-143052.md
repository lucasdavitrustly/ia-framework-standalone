## Executive Summary

This benchmark evaluated 6 prompts comparing responses with and without MCP tool access against a Java/Spring Boot payment gateway codebase. **With-MCP won 4/6 prompts** despite all RAG retrieval tools (search_codebase, search_codebase_hybrid, get_file) being **BLOCKED** due to Bad Request errors. The quality improvement came from other available MCP tools (file read, grep, glob) rather than vector-based RAG retrieval.

**Critical Finding**: The RAG pipeline was completely non-functional during this benchmark. The observed improvements are from basic file access tools only — true RAG-enhanced responses would likely show significantly larger gains.

**Judge Reliability Note**: Prompt 5 scores are unreliable due to the judge confusing the target project (Java/Spring Boot) with the ia-framework itself (TypeScript). The with-MCP response was likely more accurate than scored.

## RAG Improvement Insights

### Critical Issue: RAG Tools Completely Blocked

The primary finding is that **all 3 RAG retrieval tools were non-functional** (Bad Request errors). The benchmark measured only basic file system MCP tools — not the semantic RAG pipeline. Fixing this is the overwhelmingly top priority.

### Identified Weaknesses

- **RAG Retrieval (CRITICAL)**: search_codebase, search_codebase_hybrid, and get_file all return Bad Request
  - **Root Cause Hypothesis**: Qdrant collection not indexed for the target project, or MCP server configuration points to wrong collection/endpoint
  - **Affected Component**: packages/mcp-server (tool handlers), packages/core (indexer)

- **Judge Accuracy**: The evaluation judge confused the target project's tech stack with the ia-framework's stack
  - **Root Cause Hypothesis**: Judge prompt doesn't receive target project metadata (language, framework)
  - **Affected Component**: packages/benchmark (judge prompt template)

- **Response Time Variance**: With-MCP responses ranged from 63s to 226s — high variance suggests inconsistent tool usage
  - **Root Cause Hypothesis**: Sequential file reads without caching; no retrieval optimization
  - **Affected Component**: packages/mcp-server (tool execution strategy)

### Proposed Improvements (Prioritized)

| --- | ------------------------------------------ | ---------------------------------- | ------ | ---------------------------------------------- |

| 2   | Pass target project metadata to judge      | packages/benchmark                 | S      | Eliminates false-negative scores like Prompt 5 |
| 3   | Add collection health check to preflight   | packages/benchmark                 | S      | Early detection of indexing failures           |
| 4   | Implement retrieval caching/batching       | packages/mcp-server                | M      | -30-50% response time                          |
| 5   | Add fallback to file-grep when RAG blocked | packages/mcp-server                | M      | Graceful degradation                           |
